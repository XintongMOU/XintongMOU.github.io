**Independent Research** · City University of Hong Kong · 2025

This project develops an **ARMAX-GDEA** hybrid model for forecasting carbon allowance prices in the EU Emissions Trading System (ETS), benchmarked against standard machine learning approaches.

**Key contributions:**

- Designed three empirical experiments comparing ARMAX-GDEA against gradient boosting, LSTM, and linear baselines on ETS Phase IV data
- Evaluated predictive accuracy and model interpretability across different market regimes (pre/post-COVID, energy shock periods)
- Built the full data pipeline using Python and R for time-series preprocessing, feature engineering, and out-of-sample evaluation

**Tools:** Python (statsmodels, scikit-learn), R, EU ETS historical auction data
